# Jogniya Motors Website

A full-stack motorcycle showroom management and customer website developed for M/S. Jogniya Motors.

## Features

### Customer Website
- New motorcycle listings
- Used motorcycle listings
- Spare parts catalogue
- Bike search and price filtering
- EMI calculator
- Contact and enquiry form
- WhatsApp contact integration
- Google Maps location

### Admin Dashboard
- Secure admin login
- Dashboard statistics
- Add, edit and delete bikes
- Manage spare parts
- Upload and preview images
- View customer enquiries
- Search and filter enquiries
- Manage enquiry status

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MySQL
- REST APIs

## Installation

1. Clone the repository.
2. Open the backend directory.
3. Install dependencies:

   `npm install`

4. Create a `.env` file using `.env.example`.
5. Configure your MySQL credentials.
6. Create the `jogniya_motors` database and required tables.
7. Start the backend:

   `node server.js`

8. Open the frontend using VS Code Live Server.

## Database

Database name: `jogniya_motors`

## Project Purpose

This project provides an online platform for customers to explore motorcycles and spare parts while allowing administrators to manage showroom inventory and customer enquiries.
